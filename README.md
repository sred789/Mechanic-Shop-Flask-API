Mechanic Shop API

A RESTful API built with Flask, SQLAlchemy, and Marshmallow to manage Customers, Mechanics, and Service Tickets for a mechanic shop.
This project follows the Application Factory Pattern and uses Blueprints for modular routing.

⸻

Features
• Customer CRUD (Create, Read, Update, Delete)
• Mechanic CRUD
• Service Ticket creation and management
• Assign / Remove mechanics from tickets (Many-to-Many relationship)
• SQLite database (no MySQL required)
• Marshmallow schemas for validation & serialization
• Blueprint-based API structure
• Postman-ready endpoints
